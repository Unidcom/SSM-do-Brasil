# Modelos de Saida

Use estes modelos quando o usuario nao especificar outro formato.

## Diagnostico Editorial

```markdown
## Resumo estrategico

- Cliente:
- Periodo:
- Objetivo principal:
- Momento do cliente:
- Publico prioritario:
- Oferta/campanha:
- Tese editorial do periodo:
- Riscos ou cuidados:
```

## Pilares Editoriais

```markdown
| Pilar | Funcao no funil | Promessa editorial | Provas/insumos | Canais prioritarios |
|---|---|---|---|---|
| | | | | |
```

Cada pilar deve funcionar como uma linha de decisao, nao como categoria generica. Prefira nomes que ja indiquem o recorte editorial, por exemplo: `Prova de resultado em operacao real`, `Educacao do decisor sobre risco oculto`, `Bastidores que tornam a entrega tangivel`.

## Papel dos Canais

```markdown
| Canal | Papel | Formatos | Frequencia sugerida | Observacoes |
|---|---|---|---|---|
| LinkedIn | | | | |
| Instagram | | | | |
| Blog | | | | |
| Newsletter | | | | |
| E-mail/CRM | | | | |
```

Inclua apenas canais relevantes para o cliente. Diferencie a funcao de cada canal: descoberta, autoridade, relacionamento, nutricao, prova, conversao, comunidade ou pos-venda.

## Calendario Editorial

```markdown
| Semana/Data | Canal | Formato | Pauta | Angulo/Tese | Objetivo | CTA | Insumos/Pendencias |
|---|---|---|---|---|---|---|---|
| | | | | | | | |
```

Boas pautas devem deixar claro:

- o conflito ou pergunta que o conteudo resolve;
- a pessoa para quem foi pensado;
- a acao esperada depois do consumo;
- o insumo necessario para produzir sem inventar.

## Desdobramento Multicanal

```markdown
### Tema: [tema-guia]

| Canal | Adaptacao | Por que funciona nesse canal |
|---|---|---|
| LinkedIn | | |
| Instagram | | |
| Blog | | |
| Newsletter | | |
```

Nao replique a mesma copy. Use o mesmo tema com papeis diferentes: uma tese no LinkedIn, uma narrativa visual no Instagram, aprofundamento no blog, curadoria ou editorial na newsletter, oferta direta no e-mail.

## Brief para Producao

Quando o planejamento virar tarefa para outra skill, entregue briefs curtos:

```markdown
### Brief: [titulo da peca]

- Cliente:
- Canal/formato:
- Objetivo:
- Publico:
- Tese:
- Mensagem principal:
- Provas ou insumos:
- CTA:
- Tom:
- Cuidados:
```
