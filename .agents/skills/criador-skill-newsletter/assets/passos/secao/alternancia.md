Tipo `alternancia` — alterna entre os grupos %%GRUPOS%% a cada edição; dentro de cada grupo, ordem circular. Catálogo: `%%CATALOGO%%`.

1. Usar o grupo e o item que `rotation.py select` retornou para `%%ID%%`.
2. Cada grupo pode ter um modelo visual diferente — usar o `modelo` do item.
3. Inserir em `{{%%SLOT%%}}`. Ao confirmar, registrar também o grupo (`--grupo`).
